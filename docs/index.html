Modeling notes

Every instance has a UUID URN. Names and contact identifiers carry lexical values through CCO “is tokenized by.” A role has a church organization as its context. Recorded event dates connect an event to a day and a date identifier. Blank dates create no event or date assertion.

Names are proper names unless legal status is established. Contact endpoints use “uses,” which does not assert ownership. An address designates a contact geospatial region; it does not establish a residence or a building. Original spreadsheet values are retained as individually identified information entities.

The small entry extension adds classes only. See the church ontology and bundled CCO/BFO import.
